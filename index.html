Batasan yang diketahui

Kemampuan yang tersedia dan yang tidak diklaim

  • ✓Runs as a static HTML app with no paid API keys. Market prices use free public endpoints and are validated before display.
  • ✓Only provider responses with a valid price and observation timestamp enter the quote table and CSV export.
  • ✓Binance BTC/USDT is labelled live only when a timestamped WebSocket message is received.
  • !Stooq coverage is selective and EOD/delayed; Yahoo public endpoints are unofficial. Neither source guarantees live tick-by-tick prices or uninterrupted availability.
  • !Feed tanpa autentikasi tidak menjamin real-time. Data live berlisensi untuk indeks/futures/BEI memerlukan entitlement provider yang sesuai.
  • !No guaranteed live IDX equities feed is included. IDX real-time market data requires the appropriate licensed source.
  • !Full APIS Python orchestration, database, background automation, LLM features, issuer ingestion and persistent cloud storage are not ported into this single HTML file.
Cara menjalankan: simpan file ini di komputer lalu buka dengan Chrome, Edge, Safari, atau Firefox yang terhubung ke internet. Sebagian jaringan memblokir penyedia data pasar publik atau widget eksternal; dashboard akan menandainya unavailable dan tidak mengganti data dengan simulasi. Untuk akses provider yang lebih konsisten, file dapat dijalankan melalui web server statis lokal (opsional)—tanpa backend API.
